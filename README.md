# Task Board Demo

[English](#english) | [中文](#中文)

## English

A tiny task board used to exercise the dsh-superagent multi-developer workflow.

### Run

Open `index.html` in a browser. No build step is required.

### Files

- `index.html` — the page
- `styles.css` — all styling
- `app.js` — task list logic
